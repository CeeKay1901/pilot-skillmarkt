Kampagnen-Dashboard

Kampagnenzahlen rein, Diagramme raus. Alles rechnet im Browser, es geht nichts ins Netz.

Das ist ein Gerüst zum Weiterbauen, kein fertiges Produkt. Die Rechenwege stehen offen unter den Diagrammen.

Datenquelle

— —

CSV oder Textdatei mit Kopfzeile. Trennzeichen Semikolon, Komma, Tabulator oder senkrechter Strich werden erkannt, ebenso Komma als Dezimaltrennzeichen und Prozentzeichen.

Zahlen stattdessen einfügen

Aus Excel markieren, kopieren und hier einfügen. Die erste Zeile muss die Spaltennamen enthalten.

Überblick

—

Vergleich der Gruppen

Wie verteilt sich eine Kennzahl über eine Textspalte. Die Balken sind absteigend sortiert.

Zahlen als Tabelle

Zusammenhang zweier Zahlen

Ein Punkt ist eine Zeile aus der Datei. Zeigt, ob mehr von der einen Größe auch mehr von der anderen bedeutet.

Zahlen als Tabelle

So wurde gerechnet

Damit sichtbar bleibt, was das Werkzeug aus deiner Datei gemacht hat.

Alle eingelesenen Zeilen

Läuft per Doppelklick ohne Server, ohne Internet, ohne Installation. Nichts wird gespeichert, ein Neuladen setzt alles auf die Beispieldaten zurück.
